# 검토와 출시 준비

현재 완료: 엔진 동작 및 데이터 참조 검증. 미완료: 진로 적합성·심리측정·교육 효과의 실증 검증.

1. 진로교사·상담가가 흥미 질문의 문해 수준, 단정적 표현, 세부 직군 구별 가능성을 검토한다.
2. 직군 전문가가 14개 업무·체험 두 개의 대표성과 실제 직무 설명을 검토한다. 현재 모든 체험은 author_designed_seed.
3. 중·고·대학생 파일럿을 분리하여 질문 이해도, 모름 응답, 체험 참여율, 새로운 직업 발견, 재탐색 효과를 확인한다. 단순 추천 클릭률을 적합성 정확도로 부르지 않는다.
4. 성적·경험·접근성 차이로 추천 폭이 과도하게 줄어드는지 확인한다. 장애·환경 제약은 적성 감점으로 쓰지 않는다.
5. 같은 family 안에서 동점이 많은 한계를 업무별 흥미 문항과 실제 체험으로 보완한다. 동점 ID 정렬을 추천 정확도처럼 표시하지 않는다.
6. 교육 경로와 법정 진입요건은 공식 출처·검증일·담당자를 붙이고 분리 관리한다. 현재 null 요건을 임의 생성하지 않는다.
7. 반복 응답의 안정성, 체험 전후 변화, 전문가 평가와의 차이를 측정한다. 개인 흥미는 변할 수 있어 변화 자체를 오류로 단정하지 않는다.
8. 평가 결과를 반영한 다음 버전을 기록하고 동일 입력의 추천 변화를 설명한다. 점수·threshold 변경은 버전별 관리한다.

학생 초기 설문만으로 평생 직업을 확정하거나 합격·취업 결과를 예측할 수 있다고 홍보하지 않는다. 실제 서비스의 목표는 근거 있는 탐색과 다음 행동 지원이다.
