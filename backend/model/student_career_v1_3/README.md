# AI Career Platform v1.3 — 학생 진로 탐색 확장

작성일 2026-10-03. 기존 재직자 분석 엔진과 독립적인 학생 진로 탐색 모듈을 함께 제공한다.

## 완료 범위

기존 50개 직군·700개 업무를 기반으로 직군 탐색 카드 50개, 업무 체험 100개, 학생 진단·성찰 문항 18개, 중·고·대학생 3개 모드, 실행 가능한 추천 엔진, 3개 입력·결과 예시, 학생 테스트 13개를 추가했다. 기존 엔진 테스트 12개도 통과했다.

이번 결과는 개발 가능한 모델과 데이터 패키지다. 웹사이트·로그인·운영 서버는 아직 구현하지 않았다. 흥미 축, 직군 연결, 관련 학습 경로, 체험 과제는 저자 설계값이며 표준화된 적성검사나 실증 검증된 추천 모델이 아니다.

## 사용 흐름

학습 단계 선택 → 관심 활동 8개 응답 → 직군 후보 최대 5개 → 추천 이유·알 수 없는 점 확인 → 업무 체험 → 과정의 즐거움·재도전 의향 기록 → 추천 재계산 → 과목·교육 경로 탐색.

| 모드 | 중심 | 기본 체험 |
|---|---|---|
| middle | 관심 발견·다양한 활동 경험 | 20분, 단순 가상 사례 |
| high | 업무와 과목·전공 연결 | 40분, 두 사례 비교 |
| university | 세부 직무·결과물·준비 계획 | 60분, 근거·검증·한계 포함 |

## 실행

```bash
cd student
python3 test_student.py
python3 student_engine.py example_high.json --output my_result.json
```

Python 3 표준 라이브러리만 필요하다. 기존 재직자 엔진은 career_engine_v1_2/에 들어 있다. 학생에게 재직자 엔진의 직업 전환 날짜를 적용하지 않는다.

## 점수 해석

관심 축은 분석, 창작, 제작, 도움, 설득, 정리, 조율, 현장 활동의 8개다. 알려진 응답만 사용한다. 최소 4개 축 응답이 필요하고, 각 직군 관련 축의 최소 2/3가 응답되어야 해당 후보를 계산한다. 미응답은 0으로 처리하지 않는다.

관심지수는 해당 직군에 연결된 활동 흥미의 평균이다. 완료한 체험에서 즐거움과 재도전 의향이 모두 응답되면, 탐색지수 = 초기 흥미 70% + 해당 직군 체험 반응 평균 30%로 계산한다. 70/30, 응답 기준, 선택 기준은 검증 전 설계값이다. 체험이 없는 직군과 체험한 직군의 점수는 근거 수준이 다르므로 evidence_count를 함께 표시한다.

준비지수는 현재 자기보고 능력을 초기 업무 요구수준과 비교한 값이다. 중요한 요구 능력에 미응답이 있으면 null이다. 준비지수는 순위에 반영하지 않으며, 점수 낮음은 진입 불가능을 뜻하지 않는다. 교사 피드백·실제 결과물 기반 능력 평가는 아직 계산하지 않는다.

후보는 탐색지수 순으로 선택하되 같은 family 최대 2개로 제한해 비교 폭을 넓힌다. 동점은 ID 순이며 직업 적합성 우열을 뜻하지 않는다. 동일 family 직군이 같은 관심 태그를 공유하므로 초기 설문만으로 세부 직군을 정밀하게 구별할 수 없다. 이를 체험과 추가 질문으로 보완해야 한다.

입시 합격확률, 적성 확률, 소득 예측, AI로 인한 직업 종료일, 특정 전공의 필수 여부는 제공하지 않는다. 교육 경로는 탐색 예시이고 모든 진입요건은 not_verified다. 특정 직업의 공식 요건은 별도 출처 검증 후 연결해야 한다.

## 입력·출력

stage 필수: middle/high/university. interests는 interest_axes.json 키와 0–100 또는 null. skills는 기존 capability 키와 0–100 또는 null. weekly_minutes는 1–10080 정수. favorite_occupations는 별도 관심목록으로 유지하고 점수를 부풀리지 않는다.

activity_results는 activity_id, completed(boolean), enjoyment, repeat_interest를 받는다. 미완료 활동이나 두 반응 중 하나가 없으면 점수에는 넣지 않는다. 같은 activity_id 중복은 거부한다. 운영 서버는 학생 본인 기록과 완료 근거를 확인해야 한다.

출력은 추천 이유, 관심지수, 체험 반응, 근거 개수, 준비 상태·미확인 역량, 학습 경로, 다음 활동, 단계별 계획을 포함한다. AI 변화 설명은 업무 탐색용 정성 문구이며 추천 순위에 반영하지 않는다.
