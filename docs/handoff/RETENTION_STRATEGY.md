# 지속 방문 설계 — 분석을 행동과 변화 기록으로 연결

목표: 첫 진단 이후 ‘다음에 할 일’과 ‘내가 실제로 바뀐 점’을 제공한다. 아래 빈도는 서비스 설계 제안이며 검증된 재방문 효과가 아니다. 알림이나 자동화를 실제로 설정한 문서가 아니다.

## 권장 핵심 4개

| 기능 | 재직자 가치 | 진로 고민자 가치 | 주기·우선순위 |
|---|---|---|---|
| 나의 변화 리포트 | 실제 업무비중·AI도입·개인역할 변화와 결과 비교 | 체험반응·관심·준비상태와 후보 변화 | 월간/입력변경·P1 |
| 이번 주 작은 과제 | AI업무실험·결과검증·시간재배분 | 직군미니체험·비교·성찰·준비결과물 | 주간·P1 |
| 내 분야 업데이트 | 도구·업무방식·규제/책임 변화와 관련업무 | 새업무체험·직업이해·검증교육경로 | 새정보발생·P1 |
| 누적 기록·포트폴리오 | 실제실험·검토시간·실패·개선의 증거 | 결과물·성찰·피드백·다음활동의 축적 | 활동후·P1 |

## 재방문 루프

분석 → 목표한개 선택 → 이번주작은행동 → 결과/성찰기록 → 실제입력 또는 체험반응갱신 → 같은조건/새모델변화비교 → 다음행동.

재직자는 역할·회사도입·업무비중이 바뀌었을 때 재진단한다. 주간일지는 검증근거이며 자동 점수보너스가 아니다. 실제절약시간은 작업당전후시간·인간검토·재작업·업무범위·표본수를 함께 기록하여 단순추정과 구분한다.

진로모드는 완료체험의즐거움/재도전의향만 현재엔진에연결된다. 결과물의 숙련도·일반일지·교육수강·가치관은 현재 계산미반영이다. 과제완료만으로 적합도를 높이지 않는다. 중학생은 다양한체험,고등학생은과목/전공연결,대학생·취준생은직무결과물·검증과정을 우선한다.

## 월간 리포트

현재모델로 이전입력과현재입력을 다시 계산하여 개인변화효과를 확인한다. 별도로 같은이전입력에서 이전모델과새모델을 비교하여 모델변경효과를 보여준다. 두변화를 합산한 결과를 인간학습효과로 주장하지 않는다. 다른직군·기준연도비교는 조건차이를명시한다.

초기모델은기준연도2026/최대2040. 달력이바뀐다고자동으로연도를이동하거나예상종료일을변경하지 않는다. 신규모델은근거검토·검증·버전발행후반영한다.

## 정보 업데이트

대상: AI공식제품/연구의업무관련변화, 직군별업무방식, 검증된교육/자격경로, 서비스콘텐츠발행. 수집→중복제거→출처/날짜확인→직군/업무태깅→전문가검토→발행. source_url,published_at,checked_at,review_status,related_task_ids,왜관련되는지 필수. 일일크롤링 자체보다 근거·개인관련성을 우선.

첫버전은관리자가검토한콘텐츠로시작. 자동수집과요약은후속작업. 검증된항목없으면빈상태. 공식진입요건미확인 항목을 사실처럼 발행하지 않는다. 뉴스로모델수치를직접변경하지 않는다.

## 다음 과제 추천 규칙

입력: mode,stage,관심/위험업무,미수행과제,목표,weekly_minutes,최근완료기록. 기본 규칙: 미수행우선→현재목표관련→시간적합→이전활동과다른영역의비교활동도제시. 시간긴과제는세션분할. 검토된카탈로그만사용하고 LLM이 실제위험작업을만들지않는다.

예시 재직자: 자료초안의승인기준만들기, AI출력오류3개검토, 반복업무전후시간기록,고객문제정의연습.
예시 진로: 다른family체험,같은직군두번째업무,결과물개선전후비교,전공경로에서확인할질문작성.

## 목표·알림

사용자가선택한목표·점검시점·주간/월간빈도. 기본off. 알림종류는과제확인·검증정보변경·리포트준비. 휴면회복은사용자가구독한주기로만. 공포를유발하는종료일카운트다운·근거없는날짜단축알림은사용하지않는다. 날짜가안바뀌어도실제활동·관심변화를보여준다.

## 측정

모드별 첫결과→목표선택률,7일내실제활동률,체험성찰완료율,28일내새근거를포함한재진단률,월간리포트열람후행동률,알림해지율·도움이되었다는피드백. 방문수·출석만최적화하지않는다. 이벤트에원문응답·성찰텍스트를넣지않는다. 아직목표수치나효과검증결과는없다.
