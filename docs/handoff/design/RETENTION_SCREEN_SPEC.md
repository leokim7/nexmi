# 지속 방문 화면 상세 설계 v1.5

각 화면은 모바일 우선 반응형. 공통 컴포넌트와 오류처리 계약은 기존 디자인시스템을 사용한다.

## R-01 지속 방문 홈

- 경로 `/common/home` / 시안 `hub.html#home`
- 구성: 이번 주 과제·최근 기록·변경 안내
- 주요 이동: journal/missions
- 검증·예외: 두 모드 각자의 결과와 연결
- 상태: 최초방문·입력중·처리중·저장완료·결측·실패·재시도. 해당하지 않는 상태는 노출하지 않는다.
- 완료 기준: 실제 서버 결과와 입력스냅샷을 연결하고, 뒤로 이동해도 해당 세션 입력을 보존한다. 모바일360px·키보드 탐색·label·오류안내를 검증한다.
