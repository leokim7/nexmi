# 구현 완료 기준

## P0 E2E

1. 중·고·대 각각 시작→8응답→시간→계산→추천. 예제 입력 결과가 Python 기준과 동일.
2. 전부모름/3개응답→정보부족, 입력보존·추가답변·탐색 가능.
3. 주당시간0/문자/초과, 점수범위초과, 소속없는ID,중복체험→검증실패. 입력보존·필드메시지.
4. 네트워크실패/지연→기존입력보존·재시도·중복요청차단. 계산실패를 빈추천으로 오인하지 않음.
5. 추천밖직군 검색→상세14업무→2개체험 선택→학령별과제→활동별초안→뒤로재개→성찰→재계산.
6. 완료체험만 반영, 같은활동은 최신반응1개. 미입력준비는 null. 준비 점수로 추천순위 바꾸지 않음.
7. 0/1/3개 비교상태·4번째차단·해제·모바일스크롤·길고같은점수직군 확인.
8. 초안이탈경고·기기저장 미선택 시 재로드 후 미보존·선택후재개·저장손상·삭제·현재탭초기화.
9. 인쇄/PDF는 추천근거·체험근거·검토상태 포함. 버튼·내비게이션 제외, 잘림없음.
10. 360/390/768/1280px, 키보드-only, 200%확대, 폰트없음, 고대비·터치영역·화면낭독기 확인.

기존12+학생13 테스트 통과, 고정 입력·결과 스냅샷 parity 유지. 기능 테스트 통과와 진로 추천 타당도 검증은 별개. 실제 전문가검토·사용자파일럿은 model/의 REVIEW_PLAN.md에 따라 수행.
