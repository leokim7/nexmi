# 시안 구현 범위

실제 운영배포가 아닌 로컬리뷰용. 두모드실제엔진 연결은server.py 필요. 파일모드는예시만. 일지·기기저장은명시적버튼을선택한경우에만localStorage.

| 기능 | 시안 | 운영 구현할 부분 |
|---|---|---|
| 두 그룹 | entry.html의2선택 | 공통계정·모드별라우팅 |
| 재직자19화면 | 실제엔진·업무비중·지표·가정·What-if·기기기록 | 개인입력완료검증·서버저장·상세변경원인·현재모델비교 |
| 재직자What-if | 업무비중변경 | 조직·능력변경UI도연결,원본변경스냅샷분리 |
| 진로4단계 | jobseeker 포함실제엔진 | 행동척도·가치관수집전용설명 |
| 진로25화면 | 직군검색·대표체험·성찰·후보·인쇄 | 직군당2체험선택,활동별초안·이탈경고·영역필터 |
| 지속방문7화면 | 일지입력/기기저장·누적기록·예시과제·목표메모 | 개인화과제·목표저장·월간리포트 |
| 업데이트 | 실제패키지변경설명·외부정보빈상태 | 공식출처수집/검토/개인태깅 |
| 알림 | 선택UI·저장버튼비활성 | 채널·동의·예약·해지 |
| 계정/공유/관리자 | 명세·읽기전용/선택시안 | 인증·소유권·토큰·검토발행 |
| 리포트 | 브라우저인쇄 | 전체업무·계획·기록·선택범위 |

기기저장시모델버전·기준연도·입력스냅샷이력은시안의간단예시다. 저장손상·만료·전체이력관리·권한검증·부하제한은운영구현필요. 시안검증통과를운영준비완료나모델타당도검증으로해석하지않는다.
